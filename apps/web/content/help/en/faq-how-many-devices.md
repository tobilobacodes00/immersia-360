title: How many devices and booths can one event use?

There is no limit on devices. Register each browser that will run a booth under **Devices and team**; see [Register and manage booth devices](help:devices-and-registration). Several devices can run the same event at the same time, and each uploads its own captures.

One event can also run both kinds of booth. In the event's **Setup**, under **Basics**, switch on **Also run a Photo Booth** (or **Also run a 360 Booth**). Both booths share the event's guest pages, gallery and Live Display, and the event page gets a button to start the second one. Each booth uses its own settings section and its own design.
