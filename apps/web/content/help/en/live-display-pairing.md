Live Display shows every new capture on a TV, a projector or a laptop on HDMI, each with its own QR code, so guests can get theirs from the screen. Any device with a web browser can be a display.

## Turn it on

Open the event and go to the **Live Display** tab. **Show captures on screens** is off until you switch it on. Guests are told on their result screen that their capture may appear on the event's big screen, and each can choose **Keep mine off the screen**.

Next to it, **Publishing** decides whether new captures go up by themselves (**Show automatically**) or wait for you (**Approve first**). See [Moderate what is on screen](help:live-display-moderation).

## Pair a screen

1. In the **Displays** card press **Pair a display**. A six-character code appears, valid for 10 minutes.
2. On the screen, open the browser and go to the address shown in the window, which ends in `/tv`.
3. Type the code and press **Connect screen**.

Letters and numbers only, and never I, L, O, 0 or 1. A tablet or phone that will be the display can simply scan the QR code in the same window: that opens the pairing address with the code already filled in and pairs at once.

A code that expired shows **That code has expired. Create a new one in Studio.** Press **Get a new code**. Pairing codes are limited to 20 tries from one network every 10 minutes so they can't be guessed.

The screen remembers that it is paired in that browser. If you clear the browser's site data or use a private window, pair it again.

## Layouts and settings

Each display has its own name, layout and playback, and changes reach it within a second:

| Setting             | Choices                                                                                                                                                                                                                                                                                          |
| ------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Layout**          | **Spotlight** (one capture full screen with its QR code beside it), **Mosaic** (six to twelve playing muted, the one in turn enlarged with its QR), **Ticker** (Spotlight plus a strip of recent captures and a "just in" badge), **Counter** (the logo and how many moments have been captured) |
| **Time per item**   | 3 to 15 seconds, 8 by default. Videos play to the end, up to three times this.                                                                                                                                                                                                                   |
| **Mute videos**     | On by default.                                                                                                                                                                                                                                                                                   |
| **QR size**         | Small, Medium, Large.                                                                                                                                                                                                                                                                            |
| **Event QR corner** | The corner where the code for the whole event gallery sits.                                                                                                                                                                                                                                      |
| **Vertical videos** | **Blurred fill** or **Side by side**, for 9:16 videos on a landscape screen.                                                                                                                                                                                                                     |

A new capture jumps the queue: the item on screen is cut short, but never to under 3 seconds, so a guest standing at the screen sees theirs within seconds.

## On the screen

- **Full screen**: press **F**, or use the button in the corner.
- **Sound**: browsers block sound until someone interacts. With **Mute videos** off, a message asks you to **Press OK** (or tap) once.
- **Status** in the corner: **Live**, **Live, refreshing** (when the realtime connection is not available, the screen asks for news every few seconds, which is still within 5 seconds) or **Offline, looping saved moments**.

A screen keeps its own copy of the last 200 items and their media, so if the connection drops mid-event it keeps looping what it has instead of going blank.

## Remove or re-pair a display

**Remove** next to a display stops it at once: it goes back to its pairing page. The list shows **Online** for a display seen in the last two minutes.

> [!TIP]
> Put the display's browser in full screen and stop the TV from sleeping. See [Lock the booth for guests](help:kiosk-locking) for ideas that also work for a screen.
