Immersia 360 runs in the browser, so there is nothing to install, and it can also be added to the home screen as an app. Use a current **Chrome**, **Edge** or **Safari**. Edge uses the same engine as Chrome. The app is tested on Chrome and on Safari's engine; other browsers may work but aren't tested.

A booth needs a browser that can record video, encode H.264 video, use WebGL 2 graphics and keep files in its own storage. Most devices from the last several years do. If one doesn't, the booth says what is missing, for example **This browser can't record video. Use Chrome, Edge or Safari.**

Run the [setup check](help:setup-check) on the exact device and browser you will use: it tests all of this in a few minutes and says what to fix. Printing without a dialog needs Chrome or Edge on a computer; see [Print without a dialog](help:chrome-kiosk-printing).
