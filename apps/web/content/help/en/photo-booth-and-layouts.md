A photo booth takes one to four pictures in a row, puts them on a strip or card, shows the guest a preview and then gives them a QR code. Open the event, go to **Setup**, and find the **Photo booth** section. If your event runs both booths, both sections appear.

## The settings

| Setting                  | Choices                                                      | Notes                                                     |
| ------------------------ | ------------------------------------------------------------ | --------------------------------------------------------- |
| **Photos per session**   | 1 to 4                                                       | 3 by default.                                             |
| **Countdown**            | 0 to 10 seconds                                              | Before the first photo. 3 seconds by default.             |
| **Pause between photos** | 0 to 10 seconds, in half seconds                             | 2 seconds by default.                                     |
| **Allow retakes**        | On or off                                                    | On by default: the guest can start the session again.     |
| **Layout size**          | 2×6 strip, 4×4, 4×6 portrait, 6×4 landscape, 5×7, 9:16 story | 2×6 by default. The story size is for screens, not paper. |
| **GIF**                  | On or off                                                    | On by default. A looping GIF of the photos.               |
| **Boomerang**            | On or off                                                    | A short forward-and-back clip of the last photo.          |
| **Short video**          | On or off                                                    | A short clip around each photo, like a Live Photo.        |
| **Printing**             | On or off                                                    | See [Print at the right size](help:printing-setup).       |

The booth takes pictures at 1080p and 30 frames per second, whatever the event's video settings are.

## What the guest does

1. Taps the start button (or presses a key, see [Starting with a keyboard or remote](help:capture-triggers-and-shortcuts)).
2. Sees a countdown before every photo (the first uses **Countdown**, the others **Pause between photos**) and a flash as each one is taken.
3. Sees the finished strip with a **Looking good!** message and chooses **Keep it** or **Retake** (if you allowed retakes). If nobody touches the screen for 20 seconds the strip is kept.
4. Gets the result screen with a QR code, and a **Print** button if printing is on.

The GIF, boomerang and short video are made in the background after the guest already has their QR code, and appear on their page when ready. Boomerang and short video need the booth to keep a short rolling recording of the camera, so the booth only does that when one of them is on.

## The look of the strip

Each size comes with a ready-made layout: photos tiled over a title panel with the event name and date and, on prints, the guest's QR code and short code. Change it in **Branding** (**Print layout**) or choose one of the built-in designs. See [Templates and the editor](help:templates-and-editor) and [Looks and effects](help:looks-and-effects), which also covers the photo effect and the background.

If you change the layout size after designing a layout, the design is fitted to the new size.

## QR codes on prints

With **QR code on prints** on (in **Sharing**), each print carries a small code in the corner that opens the guest's page. It is at least 18 millimetres wide, big enough for a phone to read at arm's length. The preview the guest sees before keeping the strip shows where the code will go; the code itself is added to the kept strip.

> [!TIP]
> Test with the [setup check](help:setup-check): it takes a real test render, and for photo booths it prints a calibration sheet at your print size so you can check the paper before guests arrive.
